# Glossary

## Terms

| Term | Definition |
|------|------------|
| **Tool** | A software product/service listed in the directory |
| **Category** | One of 11 lifecycle stages (Discover, Research, Validate, etc.) |
| **Subtopic** | A sub-category within "Grow" (Retain, Automate, Scale, etc.) |
| **Speed Stack** | User's collection of selected tools for comparison |
| **Featured** | Tools marked for prominent display (shown first, with badge) |
| **Time Saved** | Estimated hours a tool saves indie hackers |
| **Affiliate URL** | Referral link for monetization |

## Categories

1. **Discover** - Finding ideas and opportunities
2. **Research** - Market and competitor analysis
3. **Validate** - Testing ideas before building
4. **Plan** - Project planning and roadmapping
5. **Design** - UI/UX design tools
6. **Build** - Development tools and boilerplates
7. **Backend** - Databases, APIs, infrastructure
8. **Ship** - Deployment and hosting
9. **Monetize** - Payments and billing
10. **Measure** - Analytics and tracking
11. **Grow** - Marketing, SEO, community building

## Grow subtopics

- **Retain** - User retention tools
- **Automate** - Marketing automation
- **Scale** - Growth scaling tools
- **Community** - Community building
- **Support** - Customer support
- **SEO** - Search engine optimization
- **Distribution** - Content distribution
