# IndieFast

IndieFast (indiefa.st) is a curated directory of indie hacker tools, designed to help solo founders and small teams discover, compare, and build their tech stack faster.

## What it does

The application displays a filterable grid of tools organized by development lifecycle categories (Discover, Research, Validate, Plan, Design, Build, Backend, Ship, Monetize, Measure, Grow). Users can browse tools, see pricing and time savings estimates, and build a "Speed Stack" of their chosen tools.

## Key features

- **Category filtering**: Filter tools by 11 lifecycle categories
- **Subtopic filtering**: Drill down into specific areas within "Grow" (Retain, Automate, Scale, etc.)
- **Speed Stack**: Add tools to a personal stack for comparison
- **Newsletter signup**: Capture leads via Airtable integration
- **Affiliate links**: Monetization through tool referrals

## Tech stack

- **Frontend**: React 19 + TypeScript + Vite + Chakra UI
- **Backend**: Express.js server with Airtable as the database
- **Deployment**: Netlify with serverless functions
